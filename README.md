# Jellyfin Online Cinema

Плагин **Online Cinema (Онлайн-кинотеатр)** для Jellyfin 12.x. Цель — каталог фильмов и сериалов TMDB в отдельном разделе Jellyfin, поиск по названию и просмотр через Prowlarr + TorrServer.

> **Статус: ранняя разработка.** До выпуска проверенной сборки не устанавливайте плагин на основной сервер. Не все пункты ниже реализованы.

## Требования

- Jellyfin 12.2.x (.NET 10)
- TMDB API v3 key
- Prowlarr с рабочими торрент-индексаторами (например, JacRed)
- TorrServer MatriX, доступный с Jellyfin-сервера
- Доступ к источникам, которые вы вправе использовать

## Интерфейс

- Отдельный раздел **«Онлайн-кинотеатр»** с фильмами и сериалами, рекомендациями TMDB и собственным поиском.
- Под постером **«В библиотеке»** — если обнаружен локальный элемент с совпадающим TMDB ID; иначе **«Онлайн»**.
- Детали сериала, сезоны и серии.
- Поиск раздач в Prowlarr, ручной выбор торрент-файла и потока в TorrServer.
- Интеграция с общим поиском Jellyfin и нативным видеоплеером — отдельные задачи, требующие проверки на Jellyfin 12.x и клиентах.

## Архитектура

```
TMDB API --> Online Cinema (Jellyfin plugin) --> каталог и поиск
Jellyfin local library --> проверка TMDB ID --> подпись под постером
Prowlarr / JacRed --> результаты раздач --> выбор раздачи
TorrServer --> HTTP-видео --> воспроизведение
```

**Важно:** TMDB предоставляет только метаданные, не видеопотоки. Плагин не содержит раздач, источников видео или API-ключей.

## Совместимость

Основа рассчитана на Jellyfin 12.2.0, как и `jellyfin-plugin-autoorganize`. Для Jellyfin 10.11 потребуется отдельная сборка. В Jellyfin 12 внешний поисковый провайдер не гарантирует появление неиндексированных виртуальных фильмов в глобальном поиске: понадобятся интеграционные тесты либо другой подход с библиотекой/веб-слоем.


## Быстрый запуск штатного плеера (версия 0.1.25.0)

При выборе раздачи плагин использует формат TorrServer `/stream/<имя>?link=<hash>&index=<id>&play`,
как в проекте `torrserver-strm-for-jellyfin`. STRM создаётся мгновенно, после чего
плагин пытается **сразу записать Movie/Episode в базу Jellyfin** через
`ILibraryManager.CreateItem`, пометив его как `IsShortcut` с прямым HTTP-адресом.
При успешной регистрации ожидания сканирования (90 секунд) нет — клиент сразу
получает настоящий ID из библиотеки и запускает штатный плеер.

Этот быстрый механизм экспериментальный: если текущая версия Jellyfin не может
регистрировать запись непосредственно, плагин сохраняет STRM и показывает
причину задержки, а не выдаёт ложное подтверждение быстрого запуска.
Выделенный HTML5-плеер старого TorrServer-плагина работает иначе и не требует
реального ID Jellyfin.

## Реальное воспроизведение через STRM (версия 0.1.21.0)

Вместо временного виртуального видеоэлемента Online Cinema может сохранять
**настоящий `.strm` внутри медиатеки Jellyfin**. Это позволяет штатной
системе Jellyfin выбирать способ воспроизведения и при необходимости использовать
FFmpeg/transcoding (поддержка конкретных кодеков зависит от устройства и настроек).

### Подготовка

1. На NAS создай две папки, доступные процессу Jellyfin для записи, например
   `/sharefolder/Video2/OnlineCinema/Movies` и `/sharefolder/Video2/OnlineCinema/Series`.
2. В **Jellyfin → Панель управления → Медиатеки** добавь первую папку в
   библиотеку типа **Фильмы**, вторую — типа **Сериалы**. Они могут быть
   также вложены в уже подключённые библиотеки соответствующего типа.
3. В **Онлайн-кинотеатр (настройки)** выбери **STRM в медиатеке Jellyfin**,
   укажи оба абсолютных пути **из окружения Jellyfin** и сохрани настройки.
4. При выборе раздачи/видеофайла плагин создаст STRM, сообщит Jellyfin об
   изменении каталога и дождётся, пока медиатека найдёт файл. Только затем
   будет выполнен запуск **реального** видеоэлемента Jellyfin.

**Именование:**

```text
Movies/
  Тайна Коко (2017) [tmdbid-354912]/
    Тайна Коко (2017).strm
Series/
  Название сериала (2024) [tmdbid-123456]/
    Season 01/
      Название сериала - S01E01.strm
```

Это примеры структуры (ID сериала демонстрационный). Сериалам для
правильного определения эпизода требуется `S01E01` или `1x01` в имени
видеофайла внутри раздачи. Если номер отсутствует, плагин попросит выбрать
другой файл и не будет придумывать сезон.

**Сохранение и удаление:** опция *«Сохранять STRM после завершения просмотра»*
включена по умолчанию. При выключении новые временные STRM, созданные плагином
в текущем сеансе сервера, удаляются после события **остановки воспроизведения**
Jellyfin с небольшой задержкой. Пользовательские файлы плагин не удаляет.
Для сохранённых файлов кнопка **STRM** появляется при следующем открытии
онлайн-карточки, в том числе после перезапуска сервера; для сериала показывается
список сохранённых эпизодов.

**Сетевые условия:** STRM содержит прямую ссылку на
`http://TorrServer:порт/play/хеш/индекс`. Она должна быть доступна именно
**серверу Jellyfin**. Плагин запрашивает сохранение раздачи в базе TorrServer,
чтобы постоянная ссылка не пропадала после перезапуска TorrServer. Если
TorrServer использует Basic Auth, создание STRM блокируется с понятной ошибкой:
пароль не записывается в файл. Вместо этого предоставь Jellyfin доступ к
TorrServer через отдельный доверенный сетевой адрес или прокси без Basic Auth
(ограниченный локальной сетью).

**Текущие ограничения:** появление нового видео зависит от времени
индексации библиотеки Jellyfin. При длительной задержке запусти сканирование
нужной медиатеки вручную. Просмотр через STRM ещё нужно проверить на
конкретном мобильном клиенте и NAS, даже при успешной сборке DLL. Глобальный
поиск Jellyfin и история просмотров онлайн-карточек требуют отдельной интеграции.

## Тест №1 — Channel playback без STRM (0.1.26)

Это отдельная экспериментальная ветка, не замена стабильной сборки.

1. Установите артефакт GitHub Actions из PR и перезапустите Jellyfin.
2. В «Онлайн-кинотеатре» выберите фильм, затем раздачу с несколькими аудиодорожками и встроенными субтитрами.
3. Плагин проверит HTTP `/stream` с помощью FFprobe самого Jellyfin, зарегистрирует ОДИН Channel item и передаст его штатному плееру. **Ни один STRM-файл не создаётся; сканирование медиатеки не требуется.**
4. В плеере проверьте видео, смену аудиодорожки, выбор субтитров и перемотку. В «Панель управления → Активность/Сеансы» проверьте режим воспроизведения; для этого теста `SupportsDirectPlay=false`, `SupportsDirectStream=false`, `SupportsTranscoding=true`.
5. Диагностика: авторизованный запрос `GET /OnlineCinema/ChannelTest/status` показывает количество найденных дорожек (без приватных URL).

Важно: тест серверной интеграции не проводился на реальном NAS. Проба FFprobe может задержаться до 35 секунд, если раздача не отдаёт байты. Поток должен быть доступен самому серверу Jellyfin. Это не готовая поддержка любого Android/Windows-клиента; тест нужен для проверки стандартного PlaybackInfo/HLS. Канал хранит только один активный выбор на сервер; выбор нового заменяет предыдущий.
